# DeedSignal MVP

A dependency-free, responsive product prototype for a Palm Beach County foreclosure intelligence platform.

**See the deal before the gavel.**

## Run locally

From this folder:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Included MVP flows

- Search and filter foreclosure opportunities
- Listing details with court case, judgment, opening bid, and estimated upside
- Save/watchlist behavior
- Auction calendar with scheduled and cancelled indicators
- Palm Beach area activity map with neighborhood scores
- Quick maximum-bid deal analyzer
- Drive-report request interaction
- Tiered Alpha, Mini-Mogul, and Mogul VIP memberships

All listing and analysis values are illustrative demo data. A production build should connect to licensed or authorized county clerk, property, title, demographic, school, and traffic data sources.
